# Prism 1.14.5（构建 6）公开测试版

本版缩小管理窗口，并让浏览器选择器按最近成功使用的顺序排列。发布目标为 macOS 15 或更新版本的 Apple Silicon 与 Intel Mac。

## 本次更新

- 管理窗口从 1120 × 900 缩小至 960 × 720，减少设置页的边距、分组间距与行距；设置内容仍可纵向滚动。
- 最近成功打开链接的浏览器在下次唤起选择器时排在第一位，其余已使用浏览器按最近使用顺序排列。尚未使用的浏览器保留原来的相对顺序，排序在重启后保留。
- 使用记录在链接成功交给浏览器后更新，覆盖手动选择、自动规则、默认浏览器与失败后的重试。打开失败不改变排序。

## 已验证

- 87 项路由核心测试、487 项原生单元测试通过。
- 回归测试覆盖成功打开、自动路由、失败后重试，以及成功交付后恢复记录保存失败的排序行为。
- 人工检查了中文浅色与英文深色界面、设置下拉控件、滚动到底部后的重置确认入口、规则编辑弹窗、浏览器管理弹窗及历史记录布局。
- Universal Release 构建、Apple Silicon／Intel 双架构、应用与安装助手签名、硬化运行时、DMG 完整性及保护生产数据的隔离启动检查通过；更新清单使用现有客户端信任的 Ed25519 密钥签名并验签通过。
- 本轮自动 UI 测试在 macOS 自动化模式初始化时超时，尚未执行用例，不计入通过结果。

## 安装与更新

已安装 1.14.3 或更新原生公测版的用户，可以在 Prism 设置中点击“检查更新”，下载并校验后确认安装。若选择安装此次未公证公测更新，该许可只对本次安装生效。

也可从 [GitHub 发布页](https://github.com/Halewwang/Prism-Browser-switching/releases/tag/v1.14.5) 下载 `Prism-1.14.5-universal-test.dmg`。退出 Prism 后，将应用拖入 Applications 替换旧版。设置、规则和历史保存在应用包外。

同一发布包含 `SHA256SUMS.txt`、`update-manifest.json` 与 `update-manifest.sig`，供完整性与更新签名校验使用。

## 公测边界

本版沿用 ad hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。更新签名只验证发布来源与文件完整性，不等同于 Apple 公证；macOS 仍可能阻止打开。

本轮未完成 Intel 实机、全部受支持 macOS 版本、真实来源应用全覆盖及 Chrome／Edge Profile 的冷启动、已运行浏览器、账号上下文与 Profile 删除验收。自动化测试和人工界面检查不替代这些实机结果。
