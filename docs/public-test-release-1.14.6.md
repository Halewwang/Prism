# Prism 1.14.6（构建 7）公开测试版

本版修复历史记录的清理与删除，合并网址和应用规则列表，并调整界面字号层级。发布目标为 macOS 15 或更新版本的 Apple Silicon 与 Intel Mac。

## 本次更新

- 修复确认清理或删除历史记录后，确认状态提前关闭导致操作未执行的问题。取消确认仍不删除记录；活动链接和可恢复队列的删除保护继续生效。
- 网址规则与来源应用规则在同一列表显示，每行用“网址／应用”标签区分。网址仍优先匹配，同类规则仍按原有优先级执行，搜索、启停、编辑、删除与调整顺序继续可用。
- 缩小页面标题、正文与辅助文字字号，用字重、颜色和间距明确层级；规则行与弹窗更紧凑。

## 已验证

- 87 项路由核心测试、489 项原生单元测试通过。
- 2 项定向 UI 测试通过，覆盖确认清理历史记录，以及统一规则列表、分类和优先级操作。
- 官网 TypeScript／Vite 构建与 ESLint 检查通过。
- 人工检查了中文浅色与英文深色界面，并确认队列仍占用链接时，清理入口保持禁用。
- 额外的队列占用 UI 用例在激活应用时超时，未完成自动化验证，不计入通过结果。

## 发布包验证

Universal Release 构建、Apple Silicon／Intel 双架构、应用与安装助手签名、硬化运行时、DMG 完整性及保护生产数据的隔离启动检查均通过；更新清单使用现有客户端信任的 Ed25519 密钥签名并验签通过。

## 安装与更新

已安装 1.14.3 或更新原生公测版的用户，可以在 Prism 设置中点击“检查更新”，下载并校验后确认安装。若选择安装此次未公证公测更新，该许可只对本次安装生效。

也可从 [GitHub 发布页](https://github.com/Halewwang/Prism-Browser-switching/releases/tag/v1.14.6) 下载 `Prism-1.14.6-universal-test.dmg`。退出 Prism 后，将应用拖入 Applications 替换旧版。设置、规则和历史保存在应用包外。

同一发布包含 `SHA256SUMS.txt`、`update-manifest.json` 与 `update-manifest.sig`，供完整性与更新签名校验使用。

## 公测边界

本版沿用 ad hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。更新签名只验证发布来源与文件完整性，不等同于 Apple 公证；macOS 仍可能阻止打开。

本轮未完成 Intel 实机、全部受支持 macOS 版本、真实来源应用全覆盖及 Chrome／Edge Profile 的冷启动、已运行浏览器、账号上下文与 Profile 删除验收。自动化测试和人工界面检查不替代这些实机结果。
