# Prism 1.14.7（构建 8）公开测试版

本版将管理界面改为顶部双胶囊导航，缩小窗口并释放正文空间。发布目标为 macOS 15 或更新版本的 Apple Silicon 与 Intel Mac。

## 本次更新

- 以顶部双胶囊取代左侧菜单：左侧融合原生红绿灯、Prism 图标与名称，右侧提供历史、规则和设置导航。窗口控制与共享提示继续由系统管理。
- 管理窗口从 960 × 720 缩小至 800 × 720；导航胶囊与窗口上方、左右保持 10pt 间距，使用更紧凑的品牌图标、字号和菜单间距。
- 中文导航中的“历史记录”精简为“历史”；移除页面中与导航重复的大标题，历史、规则和设置正文使用完整可用宽度。
- 修复切换选中态时菜单文字可能因字重变化被截断的问题，保留各菜单按内容决定宽度的布局。

## 已验证

- 87 项独立路由核心测试本轮重新运行通过。
- 本轮 490 项 Swift Testing 测试与 7 项 XCTest 测试通过。
- 首轮 5 项定向 UI 自动化中，4 项通过，覆盖顶部导航、浏览器管理、取消规则编辑，以及历史搜索和详情。
- 首轮 1 项键盘自动化用例失败。800 × 720 英文预览中的 Down／Return 操作，以及跨导航后的设置值保留，已人工检查通过。
- 导航标签固定理想水平宽度后，导航 UI 自动化重跑通过。
- 官网 TypeScript／Vite 构建与 ESLint 检查通过；更新签名测试 3 项、隔离启动规则测试 7 项通过。

## 发布包验证

Universal Release 构建及 `arm64`／`x86_64` 双架构、应用与安装助手的 ad hoc 签名、硬化运行时、无 Sparkle 动态依赖、DMG 完整性均通过核验。更新清单使用现有客户端信任的 Ed25519 密钥签名，验签通过。保护当前账号生产数据目录的隔离启动检查中，新版进程保持运行 5 秒；该检查不安装或替换现有应用。

发布采用先上传 GitHub 草稿、重新下载全部资产并复核字节大小、SHA-256 与更新签名，再公开的流程。

## 安装与更新

已安装 1.14.3 或更新原生公测版的用户，可在发布后于 Prism 设置中点击“检查更新”，下载并校验后确认安装。若选择安装此次未公证公测更新，该许可只对本次安装生效。

也可在发布后从 [GitHub 发布页](https://github.com/Halewwang/Prism-Browser-switching/releases/tag/v1.14.7) 下载 `Prism-1.14.7-universal-test.dmg`。请自行退出 Prism，将应用拖入 Applications 替换旧版。设置、规则和历史保存在应用包外。

目标发布文件还包括 `SHA256SUMS.txt`、`update-manifest.json` 与 `update-manifest.sig`，供完整性与更新签名校验使用。

## 公测边界

本版沿用 ad hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。更新签名只验证发布来源与文件完整性，不等同于 Apple 公证；macOS 仍可能阻止打开。

本轮未完成 Intel 实机、全部受支持 macOS 版本、真实来源应用全覆盖及 Chrome／Edge Profile 的冷启动、已运行浏览器、账号上下文与 Profile 删除验收。自动化测试和人工界面检查不替代这些实机结果。
