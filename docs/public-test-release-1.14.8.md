# Prism 1.14.8（构建 9）公开测试版

本版精简历史页工具栏、记录行与默认浏览器设置。发布目标为 macOS 15 或更新版本的 Apple Silicon 与 Intel Mac。

## 本次更新

- 历史页的搜索、结果筛选、记录数与清理操作集中在同一行。常用筛选直接显示，失败和处理中记录可从筛选菜单选择。
- 已取消记录的列表行移除重复的状态提示与重开按钮，重开操作仍可从更多菜单和详情使用。
- 统一历史列表中更多按钮的尺寸、图标和背景样式。
- 默认浏览器状态移到左侧标题旁，“设为默认浏览器”和“刷新”按钮更紧凑；移除该设置行的系统设置入口。
- 补齐默认浏览器操作与 HTTP／HTTPS 接管说明的中文文案。

## 已验证

- 本轮原生 Debug 构建通过。
- 人工检查了中文界面与菜单。
- 87 项独立路由核心测试、490 项 Swift Testing 测试与 7 项 XCTest 测试通过。
- 更新签名测试 3 项、隔离启动规则测试 7 项通过。
- 本轮 4 项定向 UI 自动化通过，覆盖历史清理确认与取消、搜索和详情、队列占用时的清理保护与重试，以及规则／设置页面。测试使用独立的应用标识和内存示例数据。
- 官网 TypeScript／Vite 构建与 ESLint 检查通过。

本轮未重跑完整 UI 自动化套件；此前版本的测试结果不计为本版验证结果。

## 发布包验证

Universal Release 构建及 `arm64`／`x86_64` 双架构、应用与安装助手的 ad hoc 签名、硬化运行时、无 Sparkle 动态依赖及 DMG 完整性均通过核验。更新清单沿用客户端信任的 Ed25519 密钥签名并通过验签。禁止读取或写入当前账号生产数据目录的隔离启动检查中，新版进程保持运行 5 秒；该检查不安装或替换现有应用。

发布采用先上传 GitHub 草稿、重新下载全部资产并复核字节大小、SHA-256 与更新签名，再公开的流程。

## 安装与更新

已安装 1.14.3 或更新原生公测版的用户，可在发布后于 Prism 设置中点击“检查更新”，下载并校验后确认安装。若选择安装此次未公证公测更新，该许可只对本次安装生效。

也可在发布后从 [GitHub 发布页](https://github.com/Halewwang/Prism-Browser-switching/releases/tag/v1.14.8) 下载 `Prism-1.14.8-universal-test.dmg`。请自行退出 Prism，将应用拖入 Applications 替换旧版。设置、规则和历史保存在应用包外。

目标发布文件还包括 `SHA256SUMS.txt`、`update-manifest.json` 与 `update-manifest.sig`，供完整性与更新签名校验使用。

## 公测边界

本版沿用 ad hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。更新签名只验证发布来源与文件完整性，不等同于 Apple 公证；macOS 仍可能阻止打开。

本轮未完成 Intel 实机、全部受支持 macOS 版本、真实来源应用全覆盖及 Chrome／Edge Profile 的冷启动、已运行浏览器、账号上下文与 Profile 删除验收。自动化测试和人工界面检查不替代这些实机结果。
