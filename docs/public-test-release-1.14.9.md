# Prism 1.14.9（构建 10）公开测试版

本版将《Prism · macOS Icon System》的新标志带入应用，并调整标题栏品牌胶囊的右侧留白。发布目标为 macOS 15 或更新版本的 Apple Silicon 与 Intel Mac。

## 本次更新

- 应用与 Dock 使用带透明留白的 AppIcon，16 至 1024 像素各尺寸采用对应母版，小图标单独补偿笔画。
- 标题栏使用 18pt 彩色圆形 logo，与字标保持 8pt 间距。品牌胶囊向右增加 8pt，字标右侧实际可见留白约 14.5pt；红绿灯、logo 与左边界位置保持不变。
- 菜单栏改用 18pt 单色模板标志，由 macOS 根据外观着色；欢迎页和关于窗口使用适配深浅外观的 64pt 品牌符号。
- 统一原生、旧版与官网的图标生成入口，避免后续打包覆盖为旧样式。
- 官网与 GitHub 介绍同步新版标志、规则／历史／设置和浏览器选择器截图。

## 品牌接入阶段已验证

以下验证在本轮版本号更新前完成，界面与图标代码相同，不等同于本版安装包验收：

- 24 份 SVG 母版与 41 张 PNG 的尺寸、透明通道及原色检查通过；10 个 AppIcon 槽位与对应像素资源一致，重复生成的 SHA-256 一致。
- 原生构建和 Asset Catalog 编译通过；实际检查了主窗口，以及欢迎页和关于窗口的深浅外观。
- 菜单栏与工具栏 10 项针对测试通过；右侧边距调整后，工具栏测试再次通过。实际截图对比确认红绿灯和 logo 的位置不变。
- 截图使用独立应用标识、内存示例数据和同进程窗口捕获，不读取私人链接或历史记录。

本轮版本标记更新后，官网 TypeScript／Vite 构建与 ESLint 检查通过；8 张中英文截图重命名至 1.14.9 目录，内容字节与已核验的品牌界面截图一致。

本次 1.14.9 / Build 10 重新运行了 87 项路由核心测试、490 项 Swift Testing 测试与 7 项 XCTest 测试，均通过；更新签名测试 3 项与隔离启动规则测试 7 项通过。本轮未重跑完整 UI 自动化套件。

## 发布包验证

Universal Release 构建及 `arm64`／`x86_64` 双架构、应用与安装助手的 ad hoc 签名、硬化运行时、无 Sparkle 动态依赖及 DMG 完整性均通过核验。更新清单沿用客户端信任的 Ed25519 密钥签名并通过验签；DMG 的 SHA-256 与清单一致。禁止读取或写入当前账号生产数据目录的隔离启动检查中，新版进程保持运行 5 秒；该检查不安装或替换现有应用。

发布采用先上传 GitHub 草稿、重新下载全部资产并复核字节大小、SHA-256 与更新签名，再公开的流程。

## 安装与更新

已安装 1.14.3 或更新原生公测版的用户，可在发布后于 Prism 设置中点击“检查更新”，下载并校验后确认安装。若选择安装此次未公证公测更新，该许可只对本次安装生效。

也可在发布后从 [GitHub 发布页](https://github.com/Halewwang/Prism-Browser-switching/releases/tag/v1.14.9) 下载 `Prism-1.14.9-universal-test.dmg`。请自行退出 Prism，将应用拖入 Applications 替换旧版。设置、规则和历史保存在应用包外。

发布文件还包括 `SHA256SUMS.txt`、`update-manifest.json` 与 `update-manifest.sig`，供完整性与更新签名校验使用。

## 公测边界

本版沿用 ad hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。更新签名只验证发布来源与文件完整性，不等同于 Apple 公证；macOS 仍可能阻止打开。

本轮未完成 Intel 实机、全部受支持 macOS 版本、真实来源应用全覆盖及 Chrome／Edge Profile 的冷启动、已运行浏览器、账号上下文与 Profile 删除验收。自动化测试和人工界面检查不替代这些实机结果。
