# 顶部悬浮导航与紧凑窗口

用户已确认顶部双胶囊方案，随后明确要求左右和顶部各10pt（2×截图20px）、压缩窗口宽度，并将中文“历史记录”改为“历史”。

## 最终实现

- [x] 用原生NSToolbar品牌、弹性空白和导航三个item替代左侧栏；保留AppRoute绑定。
- [x] 左侧16pt AppIcon与16pt Prism字标融合原生窗口控制；32pt胶囊背景只从自有hosting view延伸，不移动或隐藏系统按钮及共享指示器。
- [x] 右侧历史／规则／设置保留图标、文字、选中语义和键盘焦点；按内容自然宽度布局，Label使用理想水平尺寸避免选中态截断。
- [x] 原生按钮中心距窗顶26pt，32pt胶囊使顶部间距为10pt；左右外边距同为10pt。材质支持减少透明度与旧系统回退。
- [x] 管理窗口从960×720压到800×720；正文使用全宽并保留16pt边距。历史详情640pt、规则编辑520pt和浏览器管理666pt均可容纳。
- [x] 去掉历史、规则、设置页面重复的大标题，以具名无障碍内容分组保留定位；底部保留分流与本机记录状态。
- [x] Toolbar coordinator只移除自身拥有的toolbar，旧coordinator不重新接管新toolbar；缩放维持禁用。

## 验证

- 核心87项、原生490项Swift Testing与7项XCTest通过。
- 800pt定向UI初轮5项中4项通过；菜单宽度修复后导航布局重跑通过。
- 一个设置键盘自动化用例失败，日志记录外部System Settings窗口干扰；实际英文800pt预览中Down／Return及跨导航值保留手动通过，没有改共享picker产品代码。
- 中文三页与三种导航选中态实际核对完整；英文设置说明与控件无截断。
- 规则编辑、浏览器管理、历史搜索与详情窗口通过UI检查。
- macOS15实机、Intel实机、完整VoiceOver遍历及完整深色矩阵未验收。
