# Product showcase motion

P2 延续已确认的双栏布局：左侧文案与三页标签，右侧最多 560px 的完整原生截图。保留 v1.14.9 / sample data 标注，使用同一比例与同一网格单元，避免切换时布局跳动。三张图片解码成功后才开放切换。

截图进入视野后每 3.2 秒按 Rules → History → Settings 自动循环，无 Pause / Play 按钮。手动标签与 Home / End／方向键立即切换页面；焦点在 P2 区域内时跳过自动推进，避免正在查看的面板变为 `inert`。移焦到区域外后自然继续，悬停不暂停；离开视野停止计时。面板使用 150ms linear opacity 过渡，隐藏面板以 `aria-hidden`、`inert` 和禁用指针／焦点处理。减少动态效果时关闭定时轮播，保留手动切换的 150ms 淡入淡出。

P3 使用网页交互预览：固定来源应用、链接与 Cancel 头部；下方单排卡片使用真实横向 overflow，按顺序展示 Safari、Google Chrome、Dia、Arc、Firefox 五个样例。桌面约展示 3.5 张卡片，露出下一张卡片，仅保留横滑提示，无左右按钮。

P3 首次进入视野后等待 800ms，再连续往返。每轮用 1800ms 向右滚动至末端，停留 400ms，用 1800ms 返回起点，再停留 800ms；每轮共 4800ms。离开视野时停止并保存阶段，再进入视野后从该阶段续播。指针按下、焦点、键盘或滚轮输入接手时取消自动横移，直到刷新页面；减少动态效果时不自动横移。

访客可用原生横向滚动、映射为横移的鼠标滚轮或触控横滑浏览卡片；点击卡片、数字 1–5、方向键或 Home / End 可选择预览。预览不会打开本机浏览器。P1 既有完整渐入式链接流程保持不变。

本说明记录当前实现；旧版播放按钮、左右按钮及单次演示的检查结果不作为本轮证据。更新后的循环、离焦恢复与出入视野续播仍需分别验证，不将本文件视为浏览器或生产部署完成证明。物理触屏、屏幕阅读器及浏览器 Animations 面板的 10% 速度未验收。

2026-10-23 本轮本地验证：1557 × 1658 视口连续采样 10.6 秒，P2 按顺序循环并有淡入中间帧，P3 连续两轮均到达约 168.5px 后返回起点，头部固定，两类独立控制按钮均不存在。出视野暂停、保存相位并在返回后续播、聚焦标签保持页面、离焦后恢复、手动接管停止横移均通过。减少动态效果模式持续 5.2 秒无自动动画，手动面板仍使用 150ms opacity linear；320px、390px 无页面横向溢出。构建、ESLint 和独立代码复核通过，生产部署仍需单独验证。
