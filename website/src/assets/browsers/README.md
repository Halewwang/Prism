# Browser icons

- `arc.png`：取自本机 `/Applications/Arc.app/Contents/Resources/AppIcon.icns`，转换为 128 × 128 PNG。
- `firefox.png`：取自 [Mozilla Firefox 官方仓库的 default128.png](https://raw.githubusercontent.com/mozilla-firefox/firefox/main/browser/branding/official/default128.png)，为 128 × 128 PNG。
- `safari.png`、`chrome.png`、`dia.png`：沿用已有图标。
